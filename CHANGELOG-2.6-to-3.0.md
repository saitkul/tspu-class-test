# ⚡ TSPU test 3.0 — обновление с 2.6

**3.0 — это не «ещё одна версия», а переработка всего цикла работы приложения**: теперь оно не просто тестирует ТСПУ, а ведёт вас от диагноза к готовому решению — и честно говорит, когда пакетным инструментам справиться не удастся.

Обновление с 2.6 включает две большие волны изменений: **новая вкладка «Подбор» и Транспортная проверка** (2.7–3.0) и **волна стабилизации по результатам независимого код-ревью** (5 критичных багов + пачка важных, найденных двумя независимыми ревью исходников).

## 🆕 Новая вкладка «Подбор» — лесенка под РЕАЛЬНЫЕ узлы

**Одна кнопка «Запустить подбор» — всё остальное приложение делает само:**

1. **Сам слушает сеть** (30–900 с): пассивный слушатель читает имена серверов googlevideo из начала соединений — к каким узлам реально ходит ваш YouTube. Кэш провайдера отсеивается автоматически. **В это время смотрите YouTube на ПК и телефоне** — узлы появляются из вашего трафика.
2. **Прогоняет кандидатов на трудных узлах** в двух режимах: обычный curl и **с отпечатком браузера** (uTLS Chrome: hello с kyber в двух пакетах — ровно такой hello, как у настоящего браузера). Отчёт — таблица «успешных попыток на трудных узлах».
3. **Отсеивает «мягкие» узлы** (где всё проходит без труда) и **собирает готовую лесенку circular**.
4. **Применение блока одной кнопкой** «Применить блок в Zapret2» — с резервной копией конфига, проверкой после вставки и автоматическим откатом при ошибке.

**Статус-машина с явными фазами**: «ЭТАП 1/2 — Слушание сети… СМОТРИТЕ YouTube» → «ЭТАП 2/2 — Прогон кандидатов… Zapret2 остановлен — это норма» → «Подбор завершён». Кнопка запуска неактивна во время прогона, «Сейчас тестируется: …» показывает текущую стратегию, «Остановить» корректно прерывает любую фазу, прогон не может «зависнуть в финализации» — завершение фиксируется кодом выхода с хвостом лога.

**«Кандидаты из отчёта»** — персональный набор: строки, прошедшие Тест на вашем ТСПУ (или стандартный корпус 11 строк — 9 базовых механик + 2 wssize-пробы оконного фильтра — если отчёта в /tmp нет).

## 🆕 Новая вкладка «Транспорт» — диагноз первым

Проверка измеряет, **какие ТРАНСПОРТЫ проходит ваш ТСПУ**, и даёт вердикт — что делать с видео:

| Вердикт | Что значит | Что делать |
|---|---|---|
| **sni** | ТСПУ читает имена сайтов (обычная фильтрация) | Работают все стратегии nfqws2, туннель не нужен |
| **freeze** | Долгие соединения душатся по объёму (~16–20 КБ) | Туннель или дробление загрузки на много соединений |
| **ipdrop** | Узлы закрыты по адресу целиком (как Instagram по IP) | Стратегии бессильны — видео только через туннель |

- Адресная проба идёт **по всем узлам из Подбора** (до 5), с **дискриминатором** «SNI-фильтр или IP-дроп»: проба TLS с чужим именем сайта на IP узла (ICMP при этом — не показатель: он проходит и к забаненным адресам).
- Явно показывает возможности прошивки (ESP/WireGuard/xfrm) и подсказывает, какой туннель вам доступен.
- Проба заморозки — запрос файла с зарубежного дата-центра с подтверждением второй попыткой.
- Проверка идёт **фоном** (до ~1,5 мин): обновлять страницу безопасно, смотреть видео не нужно — весь трафик генерирует сама проверка.

**GGC-ремап** — пиннинг DNS живых узлов: фиксирует наблюдённые семейства узлов на их IP (запись через uci, переживает перезагрузку, снимается кнопкой). YouTube перестаёт «терять» рабочий узел при ротации DNS. Если после ремапа отдельные видео перестали играть — снимите и сравните (A/B).

## 🆕 Валидатор: проверка с отпечатком браузера

Галочка **«Отпечаток браузера (uTLS Chrome)»** — стратегия проверяется не curl'ом, а uTLS-клиентом с настоящим браузерным hello (kyber, два пакета). Убирает главный разрыв «тест зелёный — а в браузере не так».

## 🆕 Валидатор и Тест: честные вердикты

- **Честный счётчик**: AVAILABLE сбрасывается на границах блоков лога; подсчёт попыток N из M по каждой версии TLS; вердикты «НЕСТАБИЛЬНО» и «НЕ ПРОВЕРЕНА» с разбором ошибок nfqws2 («не знает функцию — обновите zapret2»).
- **Точное сопоставление стратегий с логом** — префикс больше не ловит чужие результаты.
- **Проверка адаптивности**: чемпион повторяется мгновенно; если умер — ТСПУ адаптивный, видео будет умирать через 5–15 с.

## 🆕 Генератор: 10 вариантов вместо 4

Минимальная → Усиление → Оптимальная с фейком → Лестница-страховка → Дробилка → Дробилка-Лайт → Ротор (анти-адаптив) → **Универсальная (шаблон сообщества: канон / доза-2 / без фейков)**. Каждый вариант — с пояснением, когда его брать. Применение одной кнопкой с откатом.

## 🛠 Надёжность и честность (волна стабилизации + независимое код-ревью)

- **«Остановить тест»** — кнопка в Управлении, появляется во время прогона; прогресс в статусе: «Идёт тест — N/M проверок, прошло X с».
- **Финал Подбора не теряется**: завершение фиксируется кодом выхода, после рано умершего прогона статус честно говорит «оборвался» с хвостом лога (а не висит в «финализации»).
- **Применение стратегии с fail-safe**: ожидание старта nfqws2 до 6 с; если сервис реально не поднялся — автоматический откат к предыдущему конфигу.
- **Uninstall-гигиена**: удаление останавливает все фоновые инструменты, снимает GGC-ремап, возвращает Zapret2, если его остановил наш инструмент, чистит все временные файлы.
- **Чистые логи**: каждый прогон начинается с чистого листа; снимок процессов перед сканом показывает виновника предупреждений blockcheck (VPN-туннели на роутере попадают в кадр).
- **DoH-запросы не рвутся DNS-подменами**: бутстрап через фиксированный адрес (fake-IP сервисы типа ZeroBlock больше не искажают пробы молча).
- **Очистка «Кандидаты/отчёты» останавливает идущее слушание** — статус больше не показывает устаревшие таблицы узлов.
- **IP-валидация ремапа**: мусорные адреса (локальные/фейк) не пинятся.
- **Пакеты сжаты UPX** (Go-бинарники 8,2 МБ → 2,5 МБ после установки) — после установки должно остаться ~10 МБ свободных.

## Установка

**OpenWrt 23.05 / 24.x (opkg):**
```
opkg install --force-reinstall https://github.com/saitkul/tspu-class-test/releases/latest/download/luci-app-tspu-test_3.0_all.ipk
```

**OpenWrt 25.x (apk):**
```
apk add --allow-untrusted https://github.com/saitkul/tspu-class-test/releases/latest/download/luci-app-tspu-test-3.0.apk
```

После установки выйдите из LuCI и войдите заново (или Ctrl+F5) — интерфейс гарантированно обновится. Панель: **Службы → TSPU test**.

**Примечание:** пакет вырос до ~2,4 МБ (в ipk; ~2,5 МБ после установки — Go-бинарники utlscurl/ytsniff для отпечатка браузера и поиска узлов, сжаты UPX). После установки должно остаться ~10 МБ свободных.

Баги и недочёты — в [Issues](https://github.com/saitkul/tspu-class-test/issues).
