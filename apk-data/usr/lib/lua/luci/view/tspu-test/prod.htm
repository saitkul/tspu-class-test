TSPU test — Прод-проба

Стресс повторных соединений при живом Zapret2: приложение открывает соединение к сайту примерно раз в секунду и меряет, когда появляются отказы. Адаптивный ТСПУ пропускает первые соединения и начинает резать последующие — проба ловит момент деградации по 10-секундным окнам. Это проба соединений, а не видеопотока; итоговую проверку делайте воспроизведением видео.

(10–300; за это время откроется столько же соединений)
Проба идёт при запущенном Zapret2 — меряет вашу текущую стратегию. Если Zapret2 остановлен, будет предупреждение (проба меряет голый ТСПУ).
—
Проверяет, публикует ли домен ECH-параметр в DNS (HTTPS-запись через dns.google). Граница пробы: роутерный curl не умеет ECH — реальный обход ECH проверяется браузером (Chrome/Firefox включают ECH, когда сервер его рекламирует).
