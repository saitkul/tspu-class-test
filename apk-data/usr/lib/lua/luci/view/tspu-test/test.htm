TSPU test — класс ТСПУ провайдера

Определяет, какие механики десинхронизации пропускает ТСПУ вашего провайдера: 16 стратегий (нарезка / голый фейк / комбинации) на TLS 1.2 и TLS 1.3 в режиме SCANLEVEL=force. По результатам печатается вердикт «КЛАСС ТСПУ».

На время теста служба Zapret2 останавливается и запускается обратно по завершении. Финальную проверку стратегии всегда делайте в браузере в режиме Инкогнито.

Видеотормоза/затыки при пройденном тесте? Проверьте узел googlevideo (отдельный прогон)
  1. Откройте любое видео YouTube на устройстве за этим роутером.
  2. Нажмите F12 → вкладка Network, в фильтр введите: googlevideo
  3. Наведите курсор на любой запрос videoplayback… — во всплывающей подсказке увидите URL вида https://rr1---sn-xxxx.googlevideo.com/videoplayback
  4. Скопируйте первую часть URL до /videoplayback — это узел, например rr1---sn-xxxx.googlevideo.com
  5. Запустите отдельный прогон, вписав в поле только этот узел (blockcheck2 принимает один домен за прогон). Если узел сменится в DevTools (rr2, rr5…) — повторите с новым.

Видеопоток идёт с отдельных узлов googlevideo.com — их ТСПУ может фильтровать жёстче, чем сайт: в DevTools такие обрывы видны как videoplayback … ERR_CONNECTION_ABORTED.
