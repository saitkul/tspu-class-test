TSPU test

Класс-тест ТСПУ провайдера

Определяет, какие механики десинхронизации пропускает ТСПУ вашего провайдера: 31 стратегия (нарезка / голый фейк / комбинации / двухпакетный hello / шумовая серия дробилки) на TLS 1.2 и TLS 1.3 в режиме SCANLEVEL=force. Вкладка «Тест» печатает вердикт «КЛАСС ТСПУ» и рекомендацию; «Генератор стратегий» превращает отчёт в готовые строки; «Прод-проба» меряет деградацию повторных соединений при живом Zapret2 и ECH в DNS; «Валидатор» проверяет чужие стратегии на вашем ТСПУ; «Канарейка» фоново контролирует живость текущей стратегии.

На время теста служба Zapret2 останавливается и запускается обратно по завершении. Финальную проверку стратегии всегда делайте в браузере в режиме Инкогнито.

Видео тормозит при пройденном тесте? Проверьте узел googlevideo (отдельный прогон)
  1. ВАЖНО: сканируйте КОНКРЕТНЫЙ узел, а не домен googlevideo.com — сам домен сканировать бессмысленно, будет нулевой результат.
  2. Откройте любое видео YouTube на устройстве за этим роутером.
  3. Нажмите F12 → вкладка Network, в фильтр введите: googlevideo
  4. Наведите курсор на любой запрос videoplayback… — во всплывающей подсказке увидите URL вида https://rr1---sn-xxxx.googlevideo.com/videoplayback (узел опознавайте по домену, содержащему .googlevideo.com — форма бывает разной: префикс перед --- не всегда rr и номер бывает двузначным)
  5. Скопируйте первую часть URL до /videoplayback — это узел, например rr1---sn-xxxx.googlevideo.com (подойдёт любой домен с .googlevideo.com)
  6. Запустите отдельный прогон, вписав в поле только этот узел (blockcheck2 принимает один домен за прогон). Если узел сменится в DevTools (rr2, rr5…) — повторите с новым.

Видеопоток идёт с отдельных узлов googlevideo.com — их ТСПУ может фильтровать жёстче, чем сайт: в DevTools такие обрывы видны как videoplayback … ERR_CONNECTION_ABORTED.

Дополнительно прогнать корпус по IPv6 (вдвое дольше). Нужна, если сайт/видео доступны и по v6: класс ТСПУ и рабочие строки на v6 могут отличаться от IPv4.
В терминале можно:
Остановить тест: /usr/bin/tspu-test stop
Следить за прогрессом: /usr/bin/tspu-test status
3 шага: от вердикта к работающей стратегии
  1. Скопируйте строку из блока «Рекомендация» — это готовая стратегия, которая прошла тест на вашем ТСПУ.
  2. Вставьте её в настройку стратегий Zapret2 (LuCI → Zapret2 → ваш профиль, редактор стратегий) и перезапустите Zapret2. Остальные строки профиля не меняйте.
  3. Проверьте в браузере в режиме Инкогнито (Ctrl+F5). Если сайт работает, а видео тормозит — прогоните тест по узлу googlevideo (подсказка над формой) и добавьте его строку второй.

Кнопка «Промт для нейросети» соберёт готовый запрос с вашим отчётом — вставьте его в любой чат-бот (ChatGPT, GigaChat, NotebookLM и т.п.), чтобы получить 2–3 варианта стратегии с объяснениями.

Если вердикт «не определён» — повторите тест с ожиданием 8 с и повторами 5 (рекомендация печатается в вердикте)

Секция config strategy — для /etc/config/zapret2 (терминал) или копирования строк в профиль. Строка script — то же самое в редакторе стратегий LuCI Zapret2. После применения перезапустите Zapret2 и проверьте в браузере (Инкогнито).

Кнопка записывает секцию tspu_test в /etc/config/zapret2 (в начало списка стратегий — first-match-wins), создаёт резервную копию конфига, перезапускает Zapret2. Удалить убирает секцию tspu_test целиком (списки хостов не трогаются). Список хостов подставляется по тестируемому домену (youtube → список youtube).

Стресс повторных соединений при живом Zapret2: соединение к сайту примерно раз в секунду, отказы меряются по 10-секундным окнам. Адаптивный ТСПУ пропускает первые соединения и начинает резать последующие — проба ловит момент деградации. Это проба соединений, а не видеопотока; итоговую проверку делайте воспроизведением видео.

Проверяет, публикует ли домен ECH-параметр в DNS (HTTPS-запись через dns.google). Проверка отвечает только на вопрос «обещает ли сайт такую защиту» — сам роутер её включить не может, современные браузеры используют ECH автоматически.

Проверка чужих стратегий на вашем ТСПУ: вставьте строки-аргументы nfqws2 (то, что идёт в поле script — одна стратегия на строку), укажите домен — каждая строка прогоняется через blockcheck2. Zapret2 на время скана останавливается и запускается обратно.

Вставьте стратегию ЦЕЛИКОМ — можно многострочно, как в поле script Zapret2 (строки склеиваются в одну стратегию). Без кавычек, $, ;, |, &, скобок. Несколько разных стратегий проверяйте по очереди.
