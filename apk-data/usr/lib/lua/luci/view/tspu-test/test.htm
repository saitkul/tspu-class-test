TSPU test

Класс-тест ТСПУ провайдера

Определяет, какие механики десинхронизации пропускает ТСПУ вашего провайдера: 17 стратегий (нарезка / голый фейк / комбинации / двухпакетный hello) на TLS 1.2 и TLS 1.3 в режиме SCANLEVEL=force. Вкладка «Тест» печатает вердикт «КЛАСС ТСПУ» и рекомендацию; вкладка «Генератор стратегий» превращает отчёт в готовые строки для профиля Zapret2.

На время теста служба Zapret2 останавливается и запускается обратно по завершении. Финальную проверку стратегии всегда делайте в браузере в режиме Инкогнито.

Видеотормоза/затыки при пройденном тесте? Проверьте узел googlevideo (отдельный прогон)
  1. Откройте любое видео YouTube на устройстве за этим роутером.
  2. Нажмите F12 → вкладка Network, в фильтр введите: googlevideo
  3. Наведите курсор на любой запрос videoplayback… — во всплывающей подсказке увидите URL вида https://rr1---sn-xxxx.googlevideo.com/videoplayback (узел опознавайте по домену, содержащему .googlevideo.com — форма бывает разной: префикс перед --- не всегда rr и номер бывает двузначным)
  4. Скопируйте первую часть URL до /videoplayback — это узел, например rr1---sn-xxxx.googlevideo.com (подойдёт любой домен с .googlevideo.com)
  5. Запустите отдельный прогон, вписав в поле только этот узел (blockcheck2 принимает один домен за прогон). Если узел сменится в DevTools (rr2, rr5…) — повторите с новым.

Видеопоток идёт с отдельных узлов googlevideo.com — их ТСПУ может фильтровать жёстче, чем сайт: в DevTools такие обрывы видны как videoplayback … ERR_CONNECTION_ABORTED.

В терминале можно:
Остановить тест: /usr/bin/tspu-test stop
Следить за прогрессом: /usr/bin/tspu-test status
3 шага: от вердикта к работающей стратегии
  1. Скопируйте строку из блока «Рекомендация» — это готовая стратегия, которая прошла тест на вашем ТСПУ.
  2. Вставьте её в настройку стратегий Zapret2 (LuCI → Zapret2 → ваш профиль, редактор стратегий) и перезапустите Zapret2. Остальные строки профиля не меняйте.
  3. Проверьте в браузере в режиме Инкогнито (Ctrl+F5). Если сайт работает, а видео тормозит — прогоните тест по узлу googlevideo (подсказка над формой) и добавьте его строку второй.

Кнопка «Промт для нейросети» соберёт готовый запрос с вашим отчётом — вставьте его в любой чат-бот (ChatGPT, GigaChat, NotebookLM и т.п.), чтобы получить 2–3 варианта стратегии с объяснениями.

Если вердикт «не определён» — повторите тест с ожиданием 8 с и повторами 5 (рекомендация печатается в вердикте)

Секция config strategy — для /etc/config/zapret2 (терминал) или копирования строк в профиль. Строка script — то же самое в редакторе стратегий LuCI Zapret2. После применения перезапустите Zapret2 и проверьте в браузере (Инкогнито).

Кнопка записывает секцию tspu_test в /etc/config/zapret2 (в начало списка стратегий — first-match-wins), создаёт резервную копию, перезапускает Zapret2. Откатить возвращает конфиг из резервной копии.

Полные логи на роутере: /tmp/class_test.log (сырой), /tmp/class_test.log.short (краткий, для issue) — создаются при запуске теста, очищаются при перезагрузке роутера. Скрипт: /usr/bin/tspu-test. Проект: github.com/saitkul/tspu-class-test
