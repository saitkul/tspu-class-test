TSPU test — Валидатор стратегий

Проверка чужих стратегий на вашем ТСПУ: вставьте строки-аргументы nfqws2 (то, что идёт в поле script профиля Zapret2 — одна стратегия на строку), укажите домен — приложение прогонит каждую строку через blockcheck2 и скажет, работает ли она у вас. Zapret2 на время скана останавливается и запускается обратно.

Только строки --аргументов nfqws2 (без кавычек, $, ;, |, &, скобок). Комментарии #-строки игнорируются. Нумерация результатов — по порядку непустых строк.
